Las ecuaciones de segundo grado explicadas de forma sencilla

Una ecuación de segundo grado se reconoce porque la incógnita aparece al cuadrado y en ninguna potencia mayor. Su gráfica es siempre una parábola, y la pregunta por las soluciones es la pregunta de dónde corta esa parábola al eje x. Pueden ser dos puntos, uno solo o ninguno, y precisamente esos tres casos son el núcleo del tema.

ax² + bx + c = 0  →  x = ( −b ± √(b² − 4ac) ) / (2a) La fórmula general (en los colegios alemanes se la llama «Mitternachtsformel», la fórmula de medianoche). Funciona siempre que a no sea cero
Términos clave

Forma normal — x² + px + q = 0, es decir, con a = 1 delante.
Discriminante D — la expresión bajo la raíz, b² − 4ac. Decide el número de soluciones.
Raíz (cero) — un valor de x en el que la parábola toca el eje x.
Vértice — el punto más alto o más bajo de la parábola.
Fórmulas de Vieta — para x² + px + q se cumple: x₁ + x₂ = −p y x₁ · x₂ = q.

Dos fórmulas, la misma cosa

En el colegio circulan dos fórmulas, y mucha gente las toma por métodos distintos. No lo son. La fórmula pq es solo la fórmula general para el caso especial a = 1. Si una ecuación como 2x² + 6x − 8 = 0 se divide primero entre 2, se llega a x² + 3x − 4 = 0 y se puede usar la fórmula más corta. Quien quiera evitar la división usa directamente la fórmula general. Las dos dan el mismo resultado.

x² + px + q = 0  →  x = −p/2 ± √( (p/2)² − q ) Fórmula pq — solo vale si delante de x² hay un 1

La parte decisiva de ambas fórmulas es la expresión bajo la raíz. Se llama discriminante porque discrimina, es decir, distingue: discriminare significa distinguir en latín. Si es positivo, existen dos raíces distintas y, por tanto, dos soluciones. Si es exactamente cero, las dos soluciones coinciden: la parábola toca el eje x en lugar de atravesarlo. Si es negativo, no hay solución en los números reales, porque no se puede calcular la raíz cuadrada de un número negativo. La parábola queda entonces completamente por encima o por debajo del eje.

Tres parábolas con dos, una y ninguna raíz

Ejemplo 1: 2x² − 8x + 6 = 0
a = 2, b = −8, c = 6
D = (−8)² − 4 · 2 · 6 = 64 − 48 = 16
x = ( 8 ± √16 ) / 4 = ( 8 ± 4 ) / 4
x₁ = 3, x₂ = 1

Ejemplo 2: x² − 6x + 9 = 0
D = 36 − 36 = 0
x = 6/2 = 3 (solución doble)

Ejemplo 3: x² + 2x + 5 = 0
D = 4 − 20 = −16 → sin solución real

Cuándo no hace falta ninguna fórmula

Dos tipos se pueden resolver de cabeza, y merece la pena comprobarlos antes. Si falta el término independiente, es decir, en ax² + bx = 0, se saca x como factor común: x(ax + b) = 0. Un producto es cero cuando un factor es cero, así que x = 0 o x = −b/a. Si en cambio falta el término lineal, como en x² − 49 = 0, se extrae directamente la raíz y se obtiene x = ±7. El más-menos se olvida aquí especialmente a menudo.

También es práctico el teorema de Vieta. En x² + px + q = 0, la suma de las soluciones es −p y su producto es q. En x² − 7x + 12 = 0 se buscan, por tanto, dos números que sumen 7 y multiplicados den 12: son 3 y 4. Listo, sin fórmula. En los ejercicios con soluciones enteras suele ser el camino más rápido, y sirve además como comprobación del resultado de la fórmula.

¿Y si bajo la raíz hay algo negativo? ¿Está roto el ejercicio?

Abuelo Theo

Errores habituales

Usar la fórmula pq aunque delante de x² no haya un 1. Primero hay que dividir entre a; si no, sale un disparate.
Olvidar el signo de b. Con b = −8, en la fórmula aparece −(−8) = +8.
Dar solo la solución positiva al extraer la raíz. x² = 49 tiene dos soluciones, +7 y −7.
No pasar la ecuación a cero. Ambas fórmulas suponen que a la derecha del signo igual hay un cero.

Ejercicio

Un parterre rectangular es 3 m más largo que ancho y tiene un área de 40 m². ¿Cuánto mide de ancho?

Ver solución

Ancho x, largo x + 3, área x(x + 3) = 40
x² + 3x − 40 = 0
Fórmula pq con p = 3 y q = −40:
x = −1,5 ± √(2,25 + 40) = −1,5 ± √42,25 = −1,5 ± 6,5
x₁ = 5, x₂ = −8
No existe un ancho negativo, así que el parterre mide 5 m de ancho y 8 m de largo. Comprobación: 5 · 8 = 40 m².
Recuerda: en los problemas con enunciado siempre hay que comprobar además si las soluciones tienen sentido: las matemáticas dan las dos, la realidad solo una.

Las ecuaciones de segundo grado son la puerta de entrada a todo lo que viene después: la forma del vértice, las familias de parábolas y, más adelante, las raíces de las funciones polinómicas. Quien distingue con seguridad los tres casos del discriminante ya ha superado la parte más difícil.
